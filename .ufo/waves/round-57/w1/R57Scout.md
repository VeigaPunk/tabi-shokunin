**Companion-URL rule** (`companion_urls(url, row)`, `quote-lint.py:192`):

1. Normalise the cited URL by stripping trailing punctuation `['"`,;)]}`.
2. **Siblings the row itself names**: scan the row's own `source` cell for file names with

   cited basename, add `<same directory>/<sibling>`. Only names the row states — the
   "generate every extension of every stem" variant was removed as unreachable-cost.
3. **J-STAGE**: if the URL contains `_article/`, add the same URL with `_article/` →
   `_pdf/`.
4. **own-work rows**: if `kind == "own-work"` and the URL is a repository root
   (`^https?://[^/]+/[^/]+/?$`), append the URL itself (the real evidence is local).
5. **Local artifacts** (a separate path, not a companion URL): `local_candidates()` /

   `ID-REMAP.md` and any path under `knowledge/`. A hit there is reported with the fold
   name **`local-artifact`** (a twelfth label, outside the eleven folds).

Also part of the checker's semantics (needed to prove coverage): a `sweep`-kind quote
