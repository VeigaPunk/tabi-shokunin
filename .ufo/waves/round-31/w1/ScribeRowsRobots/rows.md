## Why each row follows from its quote

- **D1** — the quote is a SHOULD on the driver's own action ("follow"), and its object is the redirect chain with the source's bound spelled out as "at least five"; the bound is the source's number, the strength is SHOULD, and the scope is stated by the source (across authorities), so the row adds nothing the sentence does not say.
- **D2** — the same bound carries a stronger obligation when the file is actually reached: "MUST be fetched, parsed, and its rules followed", so the driver decision stays "follow" at MUST and the scope is the source's ("in the context of the initial authority"). The quote stops at "followed" because the 25-word cap would otherwise cut mid-clause; the trailing scope phrase is in the same sentence (rfc9309.txt:382-383).
- **D3** — the quote is the source's own fallback above the bound: "more than five consecutive redirects" licenses only MAY ("assume that the robots.txt file is unavailable"), so the driver stops following the chain and may drop the file; the row says MAY, not MUST.
- **D4** — the number is the source's illustrative value ("for example, 30 days") for an undefined file, and the strength is MAY; the row labels it an RFC example value and names Section 2.3.1.3, the clause the quote itself points to, as the step that lets a driver proceed. The `500`-`599` signal token is the preceding sentence of the same section (rfc9309.txt:403), the observable that makes the file "unreachable"; the numeric threshold in the row comes from the quote.
- **D5** — the quote is a SHOULD NOT on the cache decision with a numeric lifetime ("more than 24 hours") and the source's own exception ("unless the robots.txt file is unreachable"); the driver action is therefore refetch, and the exception is copied into the decision cell rather than dropped.
- **D6** — the quote is a MUST on the parser's own limit with a numeric floor ("at least 500 kibibytes"); the row records a floor, not a ceiling, because that is the direction the source states. `KiB` is the source's own abbreviation ([KiB]) and the counter's unit vocabulary.
