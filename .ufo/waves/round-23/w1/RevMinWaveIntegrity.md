## Findings
- **F1 (high, fail-open).** The round-total leg is unreachable via the frozen API. `sed -n '503,505p'` → `roundCapRaw === undefined ? null : Number(...)`; `sed -n '229,231p'` gates the push on `Number.isFinite(roundCap)`. `node scripts/round-evidence-audit.mjs --rev a89f1935… --round 22 --json | jq -c '.findings[]|select(.class=="c2-wave-caps")'` → `{"cited":null,"derived":129,…,"detail":"…maxLanes 65 > policy waveMaxLanes 64"}`: the routed "129 against ≤128" defect is never cited. With `--round-cap 128` it appears (`"cited":128,…, "round total 129 spawned seats > round cap 128"`). The declared API (`--rev/--round/[--json]`) has no `--round-cap`.
- **F2 (high).** `--selftest` cannot detect F1: it calls `audit()` directly with `roundCap: 4` (`:396`, `:400`), bypassing CLI parsing, so a mutation setting the CLI default to `null` keeps 12/12 green. The in-memory mutant pair is sound for the rule and blind to its wiring.
- **F3 (high, authority split).** c2's two thresholds have two authorities: band from the policy file (correct), round cap from caller input with no recorded source. `jq -c '{roundCap,band}'` on the default run shows `roundCap:null` beside a band object — `clean:true` is then possible for a round with any number of in-band waves. Fix: default `roundCap=128` citing prompt line 192, echo `roundCapSource`, or exit 2 when unset — never silently skip.
- **F4 (medium, silent undercount).** Round total comes only from `/Spawned (\d+) background agents/` (`:44`, `:157-166`); a missing spawn receipt returns `spawned: 0`, indistinguishable from a refused wave, so a lost receipt lowers the total and protects `clean`. Round-22 happens to derive 129 correctly (`w1:64, w2:0, w2b:65`), but by luck of a nested `result.text` match (`jq -c '.spawnedSeats' .ufo/waves/round-22/w2b-spawn-result.json` → `null`; only `result.text` carries "Spawned 65"). Fix: bind `spawnedSeats` first, and treat receipt-absent as a distinct finding, not 0.
- **F5 (medium, verdict is flag-dependent).** No binding between the passed `--policy` and the round's declared shape. `node scripts/round-evidence-audit.mjs --rev a89f1935… --round 22 --policy .ufo/waves/round-23/scratch/RevMinWaveIntegrity/policy-loose.json --json` (that copy sets `waveMaxLanes:100`, sha `c2023638…`) → c2 vanishes entirely (`distinct:5`, c6 twice). So the number is genuinely read at runtime (**restated-constant failure mode is avoided**), but the v2 shape (64–128) or a declared residual wave (≤8, prompt line 199) becomes a false red under the v1 default. Require the round spec/dispatch to carry `policy` path+sha and have c2 exit 2 on a digest mismatch instead of emitting a verdict.
- **F6 (medium, moving target).** The auditor is untracked and was rewritten mid-review: `sha256sum scripts/round-evidence-audit.mjs` → `fd23c9ca…` at 04:13:06, `1092ef14…` minutes later (stable across a 2 s re-check). Nothing in the output attests the auditor's own digest, so a verdict cannot say which c2 it came from. Add `scriptSha256` to the JSON.
- **F7 (low, root cause omitted).** The w2b receipt's own policy block disagrees with the authority — `jq -c '.policy' .ufo/waves/round-22/w2b-validation.json` → `{"source":"config","maxLanes":65,"waveMinLanes":64,"waveMaxLanes":100,"hardCeiling":100}`. That divergence is *why* 65 validated, and c2's evidence never shows it; a future maintainer reading only c2 could "fix" the false red by adopting the receipt block — precisely the regression to prevent. Surface the receipt policy block in `evidence` when it differs.
- **F8 (low, scope).** `/-spec\.json$/` (`:195`) treats any top-level `*-spec.json` in the round dir as a wave; a non-wave spec (draft/assumption spec) would be band-checked. Also `maxLanes < waveMinLanes` has no exemption for a declared residual spec. Name the file class explicitly (e.g. `^w\d+[a-z]?-spec\.json$`) and document the exemption.
- **F9 (info).** Default run yields 7 findings over **6 distinct** classes (`n:7, distinct:6`), c6 twice for two different landed rows — consistent with `counterField: findings[].class (distinct count)`, but `findings|length` must never be used as the counter.
