## Findings
- **F1 (medium).** C1's round-23 verdict is undecidable while the shared report is unwritten, and fails closed — correct, but it means C1 cannot self-audit this round yet. `node scripts/round-evidence-audit.mjs --rev 03c1b4d9a9ea7719ff4a13a63989fa9be36229c3 --round 23 --round-cap 128 --json` → `refused: cannot read the round report at …/round-23/tabi.md`, exit 2. Smallest correction: report the round-23 self-audit as *owed*, not as run.
- **F2 (medium).** C1's class set is a function of the report's prose, i.e. of C2's rows.
