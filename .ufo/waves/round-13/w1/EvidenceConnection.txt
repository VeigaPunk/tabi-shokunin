2. CAUSAL SEPARATION: WHY ARIA AND DOM CANNOT COUNT AS INDEPENDENT SIGNALS
================================================================================
A. The Architectural Derivation (Correlated Engine Channels)
- In modern browser rendering engines (Chromium / Blink):
  1. The HTML parser parses markup into the DOM tree.
  2. CSS style resolution and layout compute styles and element geometries.
  3. The Accessibility Object Model (AXObjectCache / AXTree) is derived directly from the underlying DOM tree and computed styles.
  4. Playwright's `locator.ariaSnapshot()` serializes this computed accessibility tree into YAML (`- role "name" [attribute=value]`).
  5. Playwright's DOM queries (or CDP `DOMSnapshot.captureSnapshot` / `DOM.getDocument`) serialize the DOM tree nodes.
- Both ARIA snapshots and DOM snapshots are downstream projections of the EXACT SAME underlying document state in memory.
- If JavaScript mutates a DOM attribute (e.g. `button.setAttribute('aria-pressed', 'true')` or `button.textContent = 'Submitted'`), the DOM tree and the AXTree update from the identical mutation.
- If a race condition, stale state, or DOM mutation failure occurs, both the DOM snapshot and the ARIA snapshot reflect the same defect.

B. Shared Blind Spots (Why Neither Confirms Pixels or Wire)
- Neither channel sees rendered pixels:
  * An element with `class="sr-only"` (`clip: rect(0,0,0,0); position: absolute; width: 1px; height: 1px; overflow: hidden`) or `opacity: 0` is present in both DOM and ARIA snapshots, but paints ZERO visible pixels (measured case D2, SKILL.md:437).
  * Contrast failures, broken web fonts, layout overlaps, and clipping do not alter the ARIA tree or DOM tree.
  * Measured case D8 proved `:visited` links rendered 1,033 differing pixels while DOM shape was byte-identical.
- Neither channel sees wire truth:
  * Client-side JavaScript can update DOM and ARIA trees from local memory or cache without issuing a wire request (measured case D6, cache-served repeats have 0 wire lines).
  * An HTTP 500 error or client abort (measured case D4) can leave pre-existing DOM and ARIA nodes unchanged.
  * Transferred byte closure (`finEnc - body - headers = 0`, Rung 4) cannot be measured by DOM or ARIA.

C. Hard Falsification for Rung 3 (Multi-Signal)
- Rung 3 Definition (SKILL.md:373): "two or more independent signals agree (visual read-back screenshot read back visually, DOM shape, protocol metadata; two full independent runs)".
- Falsification: Pairing a DOM snapshot with an ARIA snapshot (or role locator match) provides TWO CORRELATED VIEWS of one document, NOT two independent signals.
- Invariant Rule: Agreement between an ARIA snapshot and a DOM snapshot DOES NOT satisfy Rung 3.
- Legitimate Rung 3 Triad for Accessible Interactions:
  * Channel 1 (State/Structural): ARIA snapshot YAML (Layer L6.5) OR DOMSnapshot struct (Layer L6). Choose one as the structural witness.
  * Channel 2 (Visual/Rendered): Screenshot PNG read back visually / machine-checked (Layer L7).
  * Channel 3 (Protocol/Wire): CDP Network slice ExtraInfo / byte totals (Layer L4) if a fetch claim is involved.
  * Verified across two full independent runs with cold profiles.
