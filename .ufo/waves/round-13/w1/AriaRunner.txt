8. VERDICT LOGIC
   The launcher recomputes the verdict after all workers exit. Pass only if: all 8 expected
   case IDs ran exactly once and passed; no retry/duplicate; all 4 negatives rejected with
   the asserted stable messages and tree tokens; runtime pin (versions, browser
   path/sha256/size, browser version, pin sha256) matched; the round-13 note is admitted;
   observed config is workers=1/retries=0/ignoreSnapshots=false/updateSnapshots=none/
   expectTimeout=2500/no children override; every per-case cleanup proof passed; every
   worker server closed and its port refused; page-level external aborts 0; no root output
   directories introduced; child exit 0. Otherwise verdict fail and the runner exits 1.
   Missing deps/browser/pin exits 2. Since afterAll writes only a worker receipt, a
   restarted worker still leaves per-case JSON and worker evidence for a truthful failure
   receipt; the final receipt is written by the launcher after aggregation.
