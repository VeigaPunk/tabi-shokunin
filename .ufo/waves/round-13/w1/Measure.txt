Purpose
-------
A revision-based counter. Every byte is read with `git show` / `git ls-tree`
from the named revision; nothing is read from the working tree and nothing is
executed. Missing evidence counts 0. A malformed receipt or digest mismatch
fails closed: the affected count is 0 and that mode exits 1.

Modes (run separately so one malformed claim cannot suppress the other)
-----------------------------------------------------------------------
  node .ufo/waves/round-13/measure.mjs <REV>                 # both claims + histogram + note map
  node .ufo/waves/round-13/measure.mjs <REV> --claim C1      # reads only gates.json
  node .ufo/waves/round-13/measure.mjs <REV> --claim C2      # reads only the ARIA receipt + note/index
  node .ufo/waves/round-13/measure.mjs <REV> --histogram      # reads only corpus/SOURCES.md

`--claim C1` never opens the ARIA receipt; `--claim C2` never opens
gates.json. The full mode still reports each claim's independently valid
count, but exits 1 if either receipt is malformed.
