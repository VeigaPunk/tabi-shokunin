## 2. The wheel arithmetic, reconstructed from `controls/smoke/receipt-run1.json`

### 2.1 Derivation (receipt alone)

From the receipt's own `wheellog` and `legs`, with no counter constants:

1. `wheellog` has five entries; `seq` = 1..5 strictly increasing and unique; `ts` finite, non-decreasing.
2. All five are single-notch steps of one magnitude `N`: `|deltaY|` is constant, and the sign pattern is `+,+,-,+,+`. Measuring `N` from event 0 gives **N = 120**.
3. `deltaY` is *passthrough*: an event that is not canceled advances `scrollY` by exactly its `deltaY`; a canceled event advances it by 0.
4. Exactly one event is canceled: index 3 (`defaultPrevented` true, the page-swallowed leg).
5. Hence: dispatch positions `0, N, 2N, N, N`; boundary positions `0, N, 2N, N, N, 2N`; `wheellogLen` at the boundaries `0..5`; final `scrollY = 2N`; and `pageState.scrollEvents` = number of non-canceled events = 4.
6. Pixel mode: `deltaMode 0`, `deltaX = deltaZ = 0`, `type 'wheel'`, `isTrusted`, `cancelable`, `targetId 'tall'`, all four modifier flags false.
7. Closure: `pageState.scrollY === 2N`, `wheellogLen === 5`, `scrollEvents === 4`; server witness includes `/`; teardown survivors empty, ports closed (curl 7), sweeps `0 / >0 / 0`; `failures` empty; steps = the four declared labels with `png = name + '.png'`, 64-hex digest, `bytes > 0`; producer `predicate === true` **and** `wheelHypothesis === 'CONFIRMED'`.
