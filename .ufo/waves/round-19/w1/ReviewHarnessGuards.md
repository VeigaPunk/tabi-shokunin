### Required contract delta: per-case context isolation

Round 18 launches persistent contexts and runs cases by opening/closing pages on the selected shared context (`1109–1122`, `1369–1416`, `1580–1633`, `1774–1780`). That reuse is not the round-19 validation contract: the successor must create a **fresh context and page per case**, while preserving the launch-level process, effective-argv, profile/HOME/TMPDIR, CDP-pipe and cleanup guards above. Do not carry round-18's shared-context case reuse as an isolation guarantee.

## Findings by severity

- **High — runtime identity must be strengthened for round 19.** Round 18 enforces Playwright 1.64.0, but records rather than asserts Chromium version, records Node version without checking it, and accepts `--chromium` override (`1514–1529`, `2885–2891`, `269–287`). The new receipt's runtime identity is an acceptance criterion; require exact Chromium 154.0.8037.97 / Node 24.21.0 and stable actual executable identity, not merely metadata.
- **High — effective WebMCP feature presence is not fail-closed in round 18.** It checks multiplicity, pipe, port and sandbox (`1210–1223`) but does not reject absence of `WebMCP`/`DeclarativeWebmcp` from effective feature values. Record-only `webmcpInLastEnable` (`1182–1197`) is not an assertion. Add the expected feature-content assertions in the successor.
- **Medium — existing H4 artifact check is narrower than “no download artifact.”** `scanForBytes` only looks for the unique marker and skips symlinks (`745–784`); the predicate proves that marker absent, not that no arbitrary artifact exists (`2694–2724`). Keep refusal/observation, but implement the round-19 G-H4 artifact-directory and nonce requirements separately.

## Residual risk and verification gaps

- Network confinement is scoped, not global: page HTTP(S)/beacon and WebSocket handling plus host resolver are not proof against the named non-page traffic. Also `routeWebSocket` setup failure is swallowed (`955–963`); fail closed in the successor if this guard cannot be installed.
- The Playwright enable default varies with `PLAYWRIGHT_LEGACY_SCREENSHOT` (`101–103`). Ensure the successor controls or records this input, and validate effective argv after launch.
- Round 18's successful case count and its launch controls are not a substitute for C1's fresh-context-per-case validation, runtime checks, receipt schema, or observed validation outcomes.
