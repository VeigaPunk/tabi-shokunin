Authored behavior
-----------------
Bounded JSONL claim-record validator, not an NLP/truth checker. Required record fields:
`id`, `claim`, `modality` (`observation` | `inference` | `unknown`), `evidence`
(`runtime` or `source` entries). Optional `scope`, `falsifier`, `note`; unknown fields are
rejected. The host-enforcement classification uses fixed lexical tokens only
(`host|this machine|this lane|unbranded chromium` plus `enforce*|refus*|ignore*|reject*|
block*`); it does not read the cited source or decide truth.

Stable results:
- Red fixture `m2-observation-source-only.jsonl`: `modality: "observation"`, host
  enforcement claim, source evidence only -> exit 1, finding
  `observation_without_runtime`, detail `host_enforcement_source_only`.
- Green fixture `m2-inference-source-scoped.jsonl`: `modality: "inference"`,
  `scope: "source"`, source evidence, dated falsifier -> exit 0, `CLAIM_GATE
  verdict=clean`, no FINDING line.
- Control `observation-runtime-captured.jsonl`: host-enforcement observation with
  `kind: "runtime"` evidence -> exit 0. It is a schema control only; no launch was made
  and its `control:` ref is not citable evidence.
- Additional self-test refusals: `inference_scope_missing` (inference without
  `scope: "source"`, exit 1), `inference_scope_mismatch` (source-scoped inference with no
  source evidence, exit 1), `could_not_evaluate` / `input_missing`,
  `input_symlink_refused`, `input_not_regular` (exit 2), and `no_records` (exit 1).

Self-test (isolated):
`--self-test` reads `expected.json`, verifies each persisted fixture's sha256 against its
frozen pin, copies the fixtures into a fresh `mkdtemp` root, runs the child checker there,
and asserts every expected exit/finding pair. It asserts the red and green pair above, so
both required behaviors are covered. The temp root is removed in `finally`; no network
access. Inputs are opened with `O_NOFOLLOW`, lstat-checked, and confined beneath the
declared root; symlinked, non-regular, missing and invalid-UTF-8 inputs fail closed with
exit 2.
