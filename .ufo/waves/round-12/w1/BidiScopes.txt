## 4. Key Findings & Recommendations

### F1 (Medium) — Row 10 Anchor Link Mismatch
- **Observation**: In `corpus/knowledge/webdriver-bidi-capability-matrix.md:69`, the BiDi counterpart text lists `network.beforeRequestSent`, but the anchor link is `#event-network-beforeSendRequest`.
- **Inference**: The anchor reflects an older working draft naming convention (`beforeSendRequest`) that was updated in the specification text to `beforeRequestSent`.
- **Recommendation**: Align the anchor fragment with the canonical spec anchor `#event-network-beforeRequestSent` on next note update.

### F2 (Medium) — Row 13 Client-Binding Asymmetry
- **Observation**: Row 13 (:72) introduces specific client-binding implementation status ("Selenium Python API is `_add_intercept` ... binding coverage varies"), while all other rows evaluate protocol spec anchors.
- **Inference**: Client binding APIs for WebDriver BiDi are in flux and often lag behind the W3C draft, creating a second layer of implementation uncertainty beyond browser engine support.
- **Recommendation**: Clarify in §1 or Row 13 notes that client binding support (Puppeteer, Selenium, Playwright) is distinct from both the W3C spec and browser engine capabilities.

### F3 (Medium) — Release Pin Disconnect for Local Chromium 152
- **Observation**: The local environment runs `Chromium 152.0.7977.82 Arch Linux` (verified via `chromium --version`). Unknown U1 (:117-119) asks which commands are implemented in Chromium 152 via chromium-bidi. S012 pins commit `1c6f4363b532258da7f4732deba2656a1a4fea45` of the `chromium-bidi` repository.
- **Inference**: There is no documented or pinned bridge between commit `1c6f4363` and the version of `chromium-bidi` embedded in or tested against Chromium 152.
- **Recommendation**: Record the `chromium-bidi` version bundled in Chromium 152 DEPS or map the commit to an npm release.

### F4 (Low) — Missing Commit Hash for S009
- **Observation**: In `corpus/knowledge/webdriver-bidi-capability-matrix.md:5` and `corpus/SOURCES.md:23`, S009 has a page modification date (`2026-07-23`) but no git content commit hash, whereas S006, S007, and S008 include full content hashes.
- **Recommendation**: In a future non-breaking sources refresh, pin the content commit hash for `https://www.selenium.dev/documentation/webdriver/bidi/w3c/network/`.

### F5 (Low) — Stale Historical Blog References (S010, S011)
- **Observation**: S010 (Chrome 106, 2022) and S011 (Firefox 129 / Puppeteer 23, 2024) represent historical milestones, not current capability matrices.
- **Inference**: While useful as historical context for rollout posture, they do not establish modern BiDi capability for Chromium 152 or current Firefox.
