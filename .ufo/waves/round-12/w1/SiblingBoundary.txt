### The Synthesis
Across the round's proposals, AriaEntry is authoring playwright-accessible-locators-and-snapshots.md, EvidenceLadder is connecting locators/snapshots to the four-rung evidence ladder to prevent ARIA-as-pixel/network substitutions, LocatorSource identified S023's explicit non-audit disclaimer, and PriorIntent documented the lesson of separating source inference from runtime observation (M-1).

**Admit C2 with an explicit "Client-Observation Tri-Boundary Guardrail" embedded into the knowledge note and SKILL distillation:**

   In playwright-accessible-locators-and-snapshots.md and any future SKILL distillation, explicitly anchor ARIA snapshots and role locators to Tabi's State Rung (SKILL.md:402) as structural state predicates, while appending an explicit rejection:
   "Reject: Treating role locator resolution or ARIA snapshot matching as an accessibility audit or WCAG conformance certificate. S023 explicitly bounds role locators as user-facing selectors that do not replace accessibility audits. Flip: An external, certified accessibility audit tool or compliance report (out of province -> report, never absorb)."

2. **Consumer-Only Scope for APG (Reject Publishing / Authoring Bleed):**
   Explicitly scope S025 (W3C APG) in the knowledge note as a reference for *expected query semantics* for browser driving, while refusing any authoring or markup publishing recommendations (leaving web authoring strictly to kake-shokunin).
