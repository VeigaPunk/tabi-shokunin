== Required receipt fields ==
Header: receipt_id; UTC date (ISO) and the HEAD commit at fetch; seat id; authored_note (true/false); the scorecard row and revision the claim moves; the counting command; tool versions (curl, reader) and the commands run.
Note block: note path; blob hash before; blob hash after (equal if no errata; otherwise the pre-append hash and an append-only diff); verified-at old and new; recheck field old and new.
Per claim row: claim id; source id (S###); resolved final URL after redirects; source revision (W3C dated WD URL; Playwright version heading as seen, e.g. "Version 1.64"; a chromium commit SHA, not "main"); fetch method; raw byte count; sha256 of raw bytes; pinned sha from the SOURCES Gate; pin mode (raw-sha / quote-only / version-anchor); quote ≤25 words; quote location (section, or line in the raw bytes); quote_present (yes/no, with the byte source stated); verdict (confirmed / drift / unknown).
Verdict rules: confirmed = quote present and (raw sha equal, or pin mode quote-only/version-anchor). drift = quote absent, or the quote is present but the raw sha changed in a non-reproducible way (record both; do not auto-pass). unknown = empty body, app shell, reader-only text, redirect to a different document, or network failure.

== Failure conditions (fail closed; receipt not admitted if any holds) ==
1. A note blob changed without an append-only errata block, or L1's diff finds a non-append hunk.
2. The receipt path overwrites or appends to an existing lesson, evidence or round file.
3. Fetch body empty, or sha equals the SHA-256 of the empty string (e3b0c442…).
4. Quote not found in the fetched raw bytes (or in reader text, if the receipt says so).
5. Source URL is a mutable branch (e.g. chromium main) with no resolved commit SHA recorded.
6. Source version or heading not recorded for a rolling "stable" or "Latest" page (Playwright, W3C).
7. verified-at not strictly later than 2026-10-19 used as freshness credit.
8. An early recheck presented as cadence satisfied.
9. Seat authorship not declared; anchored read order not declared.
10. Counting command absent, or not tied to the named scorecard row.
11. "Locally measured" or runtime support claimed from documentation-only rechecks (the notes say no runtime was measured; keep it that way).
12. Two wordings of the same claim found in one source (see S002 below) and only one recorded.
