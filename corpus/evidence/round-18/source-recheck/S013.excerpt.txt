. Retries ​ Playwright supports test retries . When enabled, failing tests will be retried multiple times until they pass, or until the maximum number of retries is reached. By default failing tests are not retried. # Give failing tests 3 retry attempts npx playwright test --retries = 3 You can configure retries in the configuration file: playwright.config.ts import { defineConfig } from '@playwright/test' ; export default defineConfig ( { // Give failing tests 3 retry attempts retries : 3 , } ) ; Playwright Test will categorize tests as follows: "passed" - tests that passed on the first run; "flaky" - tests that failed on the first run, but passed when retried; "failed" - tests that failed on the first run and failed all retries.
