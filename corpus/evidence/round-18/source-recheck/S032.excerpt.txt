Local WebMCP WebMCP is available as a Chrome flag for local development: Open Chrome and navigate to chrome://flags/#enable-webmcp-testing Set the flag to Enabled . Relaunch Chrome to apply the changes. Use WebMCP APIs There are two APIs you can use to set up your website tools: Imperative API : Define different types of tools with standard JavaScript, such as form input, navigation tools, state management, or other functions. Declarative API : Add annotations to a standard HTML forms to create a WebMCP tool. Note: Angular has experimental support for WebMCP .
